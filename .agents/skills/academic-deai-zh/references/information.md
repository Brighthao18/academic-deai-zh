# 信息对应与编辑收益

在实际候选稿复核时使用本页。它规定模型应判断什么；脚本只能验证证据与文本绑定和覆盖，不能自动证明语义等价。

## 信息边界

把受影响句中的信息对应到改稿中的具体原文片段。一个句子可以包含多类信息，不要先给整句贴一个标签再删除其中事实。

| 类型 | 需要保留的内容 |
|---|---|
| 研究事实或设计 | 谁对何对象做什么、组别、数量、比较及证据强度 |
| 条件和限定 | 否定、可能性、准入条件、时间、计划或完成状态及其作用对象 |
| 作者立场 | 研究目的、假设、创新声明、解释与真实承诺 |
| 引用归属 | 哪项引文支持哪项结论，及文献之间的分歧 |
| 主题 | 唯一交代的研究对象、用途、阶段或段落主题 |
| 纯行文预告 | 只说明“下面介绍”或评价自身表述，不包含上述信息的行文动作 |

“下面介绍随访安排”可以缩短为“随访安排：”，其中主题仍要保留。“本项目拟开展随访以评价持续效果”包含设计和研究目的，不能当作预告删除。已完成事项的预告可省去行文动作，但实际完成事项、阶段以及未完成事项仍须逐项对应。不能改变原文科学内容来使其更合理。

主题包括它的修饰语。“下面介绍本项目的随访安排”应保留“本项目的随访安排”，不能只留“随访安排”。“仅在成人中”“截至目前”等范围和时间也不能吸收进被删的预告。程序会拦截一部分此类漏失，但没有覆盖所有中文范围表达；仍须逐项回读。

## 原样分句与精确引用

优先用 `compact_review_template` 的简式复核。14维及claims的note逐项写清实际核查依据，程序仅免去重复抄写同一原文/改文。信息单元的简式见 [契约](contracts.md)；分类、判断、依据均由模型给出，工具只展开确定的空数组、已声明分类对应的旗标、哈希及坐标。不要把未填字段当作已经通过。

`review-request` 提供 `verbatim_candidates`：同一原段中按位置对齐、内容逐字相同的完整分句。复核者确认该分句的主体、条件、限定词、引用和上下文作用仍相同后，可在信息复核的 `verbatim_units` 填写其id、status和具体note。被确认的分句不必在units中重复拆分，也不再另填其内部的限定词；重复登记同一限定词会被拒绝。原样分句的指代或上下文作用改变时填fail/unknown，不能仅因字面相同放行。工具只计算字符对应，不生成通过判断。

其余发生变化的分句仍按完整信息单元复核。锚点引用实际主体、动作和条件的对应文字，不把整段句法壳当作动作。例如“本组拟对记录进行核查”改成“本组拟核查记录”，动作锚点前后均是“核查”，对象仍须在完整单元及object维度中核对；不能将“进行核查”和“核查”填成字面相同的锚点，也不能以保留一个动词证明整句等义。

中文后句可继承上文主体。例如“本组拟对记录进行核查，随后对异常值进行复核”中，第二个信息单元的before可以不连续引用“本组”和“随后对异常值进行复核”，after引用同一“本组”和改后的对应分句；subject引用这两侧单元内已有的“本组”，action引用“复核”。note须说明主体及“拟”的继承关系。继承所指不明确时填unknown，不臆造主体，不将其他研究/组别的主体借来充数；上文引用也必须在本次改动段内。每个涉及的动作分句仍须有独立见证。

条件锚点必须包括改变会影响事实解释的内容。“工作完成后”中的完成条件不能简化成含义较弱的“在此基础上”；名义上留下某个相同词不能代替检查先后、必要条件和范围。

仅列出的精确限定词需要binding；“后”等普通时间词在conditions中核查，不凭空新增marker。引用可用 `{text:"精确片段",occurrence:0}`；重复短语也可用 `{text:"核查",context:"本组拟对记录进行核查"}`，context须是完整文中唯一的精确片段，此时occurrence仅在context内部计数。没有重复的片段可以省略occurrence。工具找不到或遇歧义就拒绝，不做模糊匹配，也不补判pass或改变fail/unknown。

## 限定词的作用范围

逐项记录原文主体、动作、条件及限定词所作用的信息，随后寻找改稿中的对应片段。一个“拟”共用于两个动作时，两项动作都必须仍为计划；“可能影响A”和“已影响B”不能调换限定词。每个受影响的原文限定词及改稿限定词都要有来源和对应关系，未能覆盖的保留报警。

精确文本区间与全文哈希由工具核对。只提供“意思没变”或重复一个总的pass不足以放行。限定词计数的特定报警可在充分对应证据和保真复核均通过后记为模型裁决；数字、引文、结构和已经识别的关系错配不受此处理影响。原始机械检查和模型裁决分开保留。

## 收益检查

指出原句的实际问题、引用问题片段，再引用改稿中的解决片段。可接受的收益包括删除重复信息或纯预告、澄清原文已有对象、把埋在预告中的主题显露出来、减少妨碍理解的阅读顺序负担。每项收益必须在本次文本中实际出现。

保真通过且问题得到解决才保留改稿；有问题但未解决与无需修改分开记录。不能以检测器分数、作者身份、变短或改字数作为收益。
