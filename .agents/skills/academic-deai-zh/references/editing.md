# 编辑判断与文体

先问此处是否让读者更难找到研究对象、问题、证据或结论。具体收益必须能定位到原文，不能用“更像人”作为理由。

先确定问题，再生成一个针对该问题的候选。区分三种判断：有具体问题且可保真解决；文本已经清楚；有问题但当前无法保真解决。第三种要记录未解决处，不能称为“无需修改”。只是在近义词之间替换、字数变少或句式换了，不足以证明编辑有收益。

| 文体 | 可改善 | 保留 |
|---|---|---|
| 论文 | 无信息铺垫、翻译腔、完全重复论证、含混指代 | 方法、结果、效应方向、证据强弱、局限 |
| 课题申请 | 空泛包装、研究问题与技术清单之间的表述脱节 | 原设计、假设、拟开展/已完成、创新声明 |
| 综述 | 文献罗列式衔接、重复概括、缺少明确对象的评价 | 每项结论的来源、文献分歧、证据层级 |
| 研究汇报 | 无信息预告、重复小结、句内阅读负担 | 工作进度、责任主体、未完成事项、必要解释 |

允许删除纯聊天壳和不承载信息的预告；允许把“对X进行分析”改为“分析X”（只在动作、对象和范围不变时）；允许合并真正重复的表达；允许用原文已有对象澄清指代。段落整体结构重排要检查每个命题和引用的归属，避免删完包装后没有主语或推断连接。

高风险段落中的无信息预告仍可局部清理，不因含数字或统计词就一律不改。高风险命题本身优先保留原句骨架；不能借清理预告同时重写结论。编辑前后分别列清该处承载的对象、动作、条件与限定：如果只是共用一个“拟”来统领多个动作，须证明每项仍是计划状态。限定词次数改变只是一项报警，不能证明等义或不等义；新流程须提供逐项作用范围证据，无法证明时保留原文，不为过检查擅自补词。

“保守”约束事实与适用范围，不要求保留每层冗余句法。高风险段先定位一个最小阅读问题，保留有关主体、对象、动作、数值、条件、限定词及相邻命题，只整理该处。明确的动作被“对……进行了……工作”等重复壳层隔开时，可以直接表达同一动作；长定语难读时，可以用原文信息分句呈现。不必为了简化一次改完整段，也不要顺手替换否定词或合并多个“拟”。如果某一处不能保真改写，仍应检查同段是否另有可解决的问题。

例如“研究者对问卷条目进行了逐项核对工作”可整理为“研究者逐项核对问卷条目”，前提是具体上下文中的核对动作、对象、逐项范围与完成状态都未改变。“含数字”“条件重要”“任何压缩可能漏信息”只是风险提示，不能单独作为整段无需编辑的依据。确实未找到安全改法时保留原文，并明确记录那个尚未解决的问题。

预告句不一定全是空话。删除前检查，其中是否唯一交代了研究对象、活动用途、阶段或本段主题；若正文没有重复这些信息，应保留并接入缩短后的表述。不能先把整句归为“包装”，再忽略其中的信息。

对实际修改，按 [信息与编辑收益](information.md) 区分研究事实、条件、作者立场、引用归属、主题和纯行文预告。只允许省去行文动作或对表述的自我评价；研究目的、实际承诺、假设、创新声明和阶段状态属于须保留的信息。混合句先保留其信息，再简化预告。复核原文与改稿时采用同一边界，不能要求逐字保留纯预告，也不能因删去预告而放过其他信息遗漏。

候选理由要引用具体原文问题，并说明改稿如何解决它。复核者分别判断保真与收益：原文已经清楚、只换近义词、只少几个字、或只是换一种语序时，不据此通过收益检查。若编辑问题仍在或产生新的阅读障碍，记录“问题未解决”，保留原文。

删除重复句前核对是否重复同一命题、条件和来源。当前机械层只对同段相邻、逐字相同、仍保留一个完整副本的整句提供限定词计数例外；数字、引用、结构及语义复核仍受原约束。近似重复、跨段复现和带不同引文的相似句没有自动例外。

原文“首次发现”“具有临床价值”“填补空白”可能是作者主张，不能在风格编辑时随手删去或偷偷改弱；可提示需核实依据。“显著”可能是统计结论，必须先判定上下文。普通套语若承担章节用途、正式语体或论证层级，无明确问题可保持原样。

反例：真实三项措施三项都留；施事者未知的被动不能补主语；必要长句可保留；闭环反馈、转化医学、内稳态等专业术语不当空泛词处理；“旨在评估”是正常研究目的；真实背景条件不能因“随着”而删；范围纠错“不适用于X而适用于Y”必须保留；引用编号保持但支持结论改变仍是失败。

规则扫描只是定位入口，模型还要检查段落重复、指代和衔接。无规则证据的问题可写个案诊断，不能立刻升级成通用禁令。需修改但改法不确定时给建议并保留原文；记录未解决问题，不能靠全部no-op宣称有效。
