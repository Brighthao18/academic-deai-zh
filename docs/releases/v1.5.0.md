中文学术文本去 AI 味 Skill：改善模板腔、空泛套话、重复铺垫和机械衔接，同时保留事实、数字、专业术语、条件与引文。面向论文、课题申请、综述与研究汇报，优先支持医学与生命科学。

本版为首次公开发行，基于本地 1.4.0 运行版。

- 使用 MIT 许可证，公开代码、文档、合成示例与离线工程测试。
- 提供可安装的独立 Skill ZIP、逐文件清单及 SHA256SUMS。
- 增加安装工具、公开范围检查，以及 Windows/Linux 的自动测试。
- 保留现有数字、引文、信息、收益复核与回退机制；补丁 schema 仍为 1.0。

下载 `academic-deai-zh-v1.5.0.zip` 并将完整技能目录放入 `.agents/skills`。使用源码的安装与验证说明见 README。

完整编辑需要 Codex 会话。CLI 不调用模型；工程测试通过不证明写作效果，Word 保格式回写尚未支持。
