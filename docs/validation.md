# 验证范围

本公开版验证的是本地运行、数据保护和分发可复现性。公开测试完全离线，不读取本地研发语料，不调用模型或要求账号。

覆盖的行为包括：Unicode 坐标、数字与引文保护、数值和组别绑定、限定条件、补丁依赖和原子事务、陈旧哈希拒绝、缺失或失败复核回退、简式复核、上下文引文定位、BOM 与混合换行保留、重复输出拒绝和原稿字节保留。

发行工具使用固定文件顺序和 ZIP 元数据；相同来源文件生成相同发行字节。分发测试会在含中文与空格的独立目录解压、安装并运行 CLI，也会检查非公开文件没有进入压缩包。

测试中的 `SIMULATED` 复核只验证门控程序能否正确处理指定输入。它不能证明模型判断可靠、改稿完全等义或风格改善。CLI 不会自动补充语义判断。无复核或失败复核下的回退是预期结果。

本项目在公开前进行过开发验证，但这些开发材料与公开测试范围不同。总体写作收益仍未证明，缺乏独立人工金标准；不把开发回放、合成样本或工程测试外推为普遍有效性。1.5.0 是分发和维护改造，不宣称提升写作效果。

可复现的检查命令见根目录 README，跨平台结果见 GitHub Actions。具体公开发行检查记录见 [release-verification.json](release-verification.json)。
